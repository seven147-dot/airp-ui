# AIRP UI

面向 SillyTavern 的角色扮演扩展，用手机界面管理人物、私聊、朋友圈、论坛、人物关系和世界事件。

当前版本：**0.9.1**，存档状态版本：**14**。这是供朋友体验的版本；真实模型和移动端网络尚未完成端到端验证。

## 安装

需要已经安装并能正常聊天的 SillyTavern，以及你自己的模型连接。本扩展不提供模型服务、API 密钥或额外服务器。

在 SillyTavern 中打开 **扩展 → 安装扩展**，粘贴下面的仓库地址，完成安装后刷新页面：

```text
https://github.com/seven147-dot/airp-ui
```

**直接链接安装以仓库公开为前提。** 私有仓库需要下载者拥有访问权限及对应的 Git 身份验证；普通粘贴链接通常无法安装。仅邀请好友成为 GitHub 协作者，并不等于酒馆所在设备已经登录 GitHub。

也可以将仓库下载为 ZIP，解压后把含有 `manifest.json` 的目录放到酒馆的 `data/<用户目录>/extensions/airp-ui/`。默认用户的路径为 `data/default-user/extensions/airp-ui/`。确认不要出现 `airp-ui/airp-ui/manifest.json` 这样的额外嵌套；重新加载酒馆页面。

仓库根目录必须保留 `manifest.json` 和脚本；`提示词/`、`世界包/` 中的文件也必须一起安装，不能只复制 JavaScript 文件。

## 第一次使用

1. 在酒馆中配置模型与玩家 Persona。Persona 决定玩家的身份和背景。
2. 建立用于承载世界剧情的聊天。建议使用单独的叙事宿主卡，可参考 [主叙事卡草稿](主叙事卡/主叙事卡草稿.md)。这份文件是配置参考，不是可以直接导入的角色卡 JSON；仓库没有附带现成的人物角色卡。
3. 从酒馆扩展菜单打开 **AIRP 手机**。在 AIRP 设置中启用开发者模式，进入人物列表，通过 **＋** 从已导入酒馆的角色卡中加入人物。加入人物不会切换当前剧情聊天。
4. 检查 AIRP 的自动状态追踪和上下文注入已开启。默认附带“学院世界”，其资料位于 `世界包/学院世界/`；可以在设置中检查世界包与规则是否加载成功。
5. 在同一聊天中推进剧情。AIRP 在模型回复后读取状态块，再更新人物、事件与社交内容。世界进度按聊天保存。

人物加入世界不代表已经加好友。与玩家成为好友之后，才能私聊、查看或互动对方的朋友圈；论坛保持公开。模型生成日常帖子和 NPC 需要遵守 AIRP 状态协议，安装后不会立即凭空填满社交页面。

## 已知问题

- **角色卡人物关系初始化尚不完整。** 当前由模型提取并输出 `characterRelations`；模型只填人物资料时，也可能被标记为资料初始化完成，关系漏填后没有独立检查与重试。人物关系页可能仍为空。
- 关系双方需要已经登记为 AIRP 人物，模型必须使用准确的角色 ID。正文中的关系描述不会自动成为关系记录。内嵌世界书的关系条目也不保证进入 AIRP 提供的卡片摘要。
- 场外人物卡和长文档受上下文预算限制。状态输出是否完整还取决于模型，不保证每轮都产生动态、论坛、NPC 或关系变化。
- 尚未确认兼容的最低 SillyTavern 版本；如出现扩展无法加载或事件接口不可用，需要记录酒馆版本再排查。

人物关系为空时，可以先向模型发送：

> 暂停推进剧情，依据当前可见角色卡补填已登记 AIRP 角色之间尚未记录的关系。在 `<AIRP_STATE>` 的 `characterRelations` 中使用角色索引的准确 ID，填写关系摘要、标签、来源依据与双方印象。保留已经由剧情产生的关系变化，不编造缺少依据的关系。看不到卡内关系原文、或者人物尚未登记时，请明确说明缺少什么。

必要时在指令后附上卡内关系原文。

## 保存与手机访问

- 正常进度通过酒馆聊天 metadata 保存到你自己的酒馆服务器；本机恢复副本存放在当前浏览器中。
- 手机远程访问时，共享进度依赖服务器保存。更换设备、浏览器或访问地址后，不能直接读取另一个浏览器或网站来源的本机恢复副本。
- 遇到保存错误或本机与服务器副本冲突时，先导出进度，再按界面提示选择恢复。建议同时只在一个设备推进同一聊天。
- 更新前建议在 AIRP 中导出进度备份。通过酒馆的扩展管理更新后，电脑和手机都需要刷新页面。

仓库只分发扩展、规则与示例世界，不包含聊天存档、角色卡、个人设置或密钥。

## 文件与验证

- `index.js`：酒馆对接、人物和社交系统、状态处理及界面。
- `prompts.js`、`提示词/`：模型状态输出协议与叙事规则。
- `airp-core.js`：状态校验、变化量与历史重建。
- `airp-storage.js`：本机恢复副本。
- `style.css`：手机界面样式。
- `世界包/`：默认世界资料。
- `tests/airp-regression.cjs`：模拟上下文中的回归验证，不调用真实模型或写入实际聊天存档。

验证命令：`node tests/airp-regression.cjs`。发布前 42 项回归验证通过。0.9.1 的新增控件在隔离浏览器中检查了 32 组布局（320 / 375 / 430 / 1280 像素），未发现横向溢出，折叠、键盘焦点与减少动画设置检查通过；这些结果不代表真实模型、服务器和移动端均已验证。
